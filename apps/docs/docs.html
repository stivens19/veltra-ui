1. Introducción y Visión de VeltraUI 1. Introduction & VeltraUI Vision

Filosofía de diseño moderna, alto rendimiento y sin deuda técnica Modern design philosophy, high performance, and zero technical debt

VeltraUI es un sistema de diseño y suite de plantillas administrativas de última generación concebido para resolver las limitaciones históricas de las plantillas de panel de control. A diferencia de las herramientas del pasado que acumulaban capas pesadas de jQuery, preprocesadores Sass incompatibles con herramientas modernas y hojas de estilo infladas con miles de selectores en desuso, VeltraUI adopta los estándares web contemporáneos:

  • Tailwind CSS v4 Nativo Aprovecha el nuevo motor Oxide y LightningCSS para compilar en milisegundos sin configuraciones engorrosas.
  • Cero Dependencia de Sass Variables CSS nativas en tiempo de ejecución y selectores anidados compatibles con Laravel Vite, React, Vue y Angular.
  • Modo Oscuro Anti-FOUC Algoritmo de inicialización ultra-temprana que previene el destello blanco antes del primer frame de renderizado.
  • TypeScript Declarativo Controladores interactivos ligeros mediante atributos HTML data-vlt-* sin necesidad de escribir código JavaScript manual para cada componente.

VeltraUI is a cutting-edge administrative design system and dashboard template suite built to overcome legacy hurdles in admin panels. Instead of relying on legacy jQuery plugins, heavy Sass preprocessors incompatible with modern bundlers, or bloated CSS bundles, VeltraUI is built directly on contemporary web standards:

  • Native Tailwind CSS v4 Leverages the Oxide engine and LightningCSS to bundle styles in milliseconds with zero configuration overhead.
  • Zero Sass Dependency Pure native CSS runtime variables and nesting, ready for immediate use in Laravel Vite, React, Vue, and Angular.
  • Anti-FOUC Dark Mode Ultra-early head script execution preventing white flashes before the browser renders the first frame.
  • Declarative TypeScript Lightweight controllers triggered via declarative HTML attributes data-vlt-* without requiring bespoke JS code for every element.

3. Uso de la Carpeta dist/ y Live Server 3. Using dist/ & Live Server Setup

Cómo previsualizar las plantillas compiladas evitando restricciones de seguridad CORS How to preview compiled templates without local browser CORS restrictions

Si descargaste la carpeta precompilada dist/ o se la compartes a un cliente o compañero de equipo, encontrarás las 39 plantillas HTML optimizadas, las hojas de estilo CSS compiladas y los activos estáticos listos para usar sin necesidad de configurar Node ni pnpm.

¿Por qué se debe usar Live Server al abrir la carpeta dist/?

Aunque los estilos CSS y la maquetación visual cargan al abrir los archivos HTML con doble clic directo, los navegadores modernos (Chrome, Edge, Firefox, Safari) cuentan con una estricta política de seguridad (CORS) que bloquea la ejecución de módulos JavaScript (<script type="module">) cuando se abren bajo el protocolo local de disco file:///.

Para que todas las interactividades dinámicas funcionen al 100% (gráficos interactivos de Chart.js, menús desplegables, modales y renderizado reactivo de iconos), se debe servir la carpeta dist/ a través de un servidor HTTP local.

4 Opciones Sencillas para Ejecutar con Servidor Local:

1. Live Server de VS Code (Recomendado)

Abre la carpeta dist en VS Code, haz clic derecho sobre index.html y pulsa "Open with Live Server".

2. Node / npx (Sin instalación previa)

Abre una terminal dentro de dist y ejecuta:
npx serve .

3. Python (Si tienes Python instalado)

Dentro de la carpeta dist ejecuta:
python -m http.server 3000

4. Directo con pnpm (En el monorepo)

Desde la raíz del repositorio ejecuta:
pnpm docs:preview

If you downloaded the pre-built dist/ package or share it with clients and team members, you will find all 39 production-ready HTML templates, compiled CSS bundles, and static assets ready to use without requiring Node or pnpm.

Why you must use Live Server when testing the dist/ folder:

While layout styling and CSS render properly when double-clicking HTML files, modern browsers (Chrome, Edge, Firefox, Safari) enforce a strict CORS security policy that blocks JavaScript ES modules (<script type="module">) when loaded from the local disk scheme file:///.

To ensure all dynamic behaviors execute at 100% (Chart.js graphs, dropdown menus, modals, and reactive Lucide icons), always serve the dist/ folder over a local HTTP server.

4 Simple Ways to Serve with a Local Server:

1. VS Code Live Server (Recommended)

Open the dist folder in VS Code, right click on index.html, and select "Open with Live Server".

2. Node / npx (Zero installation)

Open your terminal inside dist and run:
npx serve .

3. Python (If Python is installed)

Inside the dist folder execute:
python -m http.server 3000

4. Monorepo pnpm command

From the workspace root directory execute:
pnpm docs:preview

Modo React / Next.js: Creando Componentes Reutilizables

Importa veltra.css en tu archivo de entrada y convierte cualquier bloque HTML sustituyendo class por className:

src/components/StatBox.jsx 
import React from 'react';
import { ArrowRight } from 'lucide-react';

export function StatBox({ color = 'cyan', title, value, meta, icon: Icon, link = '#' }) {
  return (
    <div className={`vlt-stat-box vlt-stat-box-${color}`}>
      <div className="vlt-stat-box-inner">
        <div className="stat-top">
          <div className="stat-icon-wrapper">
            {Icon && <Icon className="w-6 h-6" />}
          </div>
        </div>
        <div className="stat-value">{value}</div>
        <div className="stat-title">{title}</div>
        {meta && <div className="stat-meta"><span>{meta}</span></div>}
      </div>
      <a href={link} className="vlt-stat-box-footer">
        <span>Más información</span>
        <ArrowRight className="w-3.5 h-3.5 footer-arrow" />
      </a>
    </div>
  );
}

Modo Angular (v17/v18+): Componente Standalone

Agrega veltra.css en tu archivo angular.json y vincula propiedades con @Input():

src/app/components/stat-box/stat-box.component.ts 
import { Component, Input } from '@angular/core';
import { CommonModule } from '@angular/common';

@Component({
  selector: 'app-stat-box',
  standalone: true,
  imports: [CommonModule],
  template: `
    <div class="vlt-stat-box" [ngClass]="'vlt-stat-box-' + color">
      <div class="vlt-stat-box-inner">
        <div class="stat-value">{{ value }}</div>
        <div class="stat-title">{{ title }}</div>
        <div class="stat-meta" *ngIf="meta"><span>{{ meta }}</span></div>
      </div>
      <a href="#" class="vlt-stat-box-footer"><span>Ver detalles</span></a>
    </div>
  `
})
export class StatBoxComponent {
  @Input() color: string = 'cyan';
  @Input() title: string = '';
  @Input() value: string = '0';
  @Input() meta: string = '';
}

6. Tailwind CSS v4 y Arquitectura Zero-Sass 6. Tailwind CSS v4 & Zero-Sass Architecture

Por qué migrar de Sass a CSS nativo fue la decisión de ingeniería correcta Why dropping Sass for native CSS was the optimal engineering decision

Históricamente, los desarrolladores utilizaban Sass por tres razones principales: variables ($color), anidamiento de selectores (nesting) y mixins. Con la especificación oficial de CSS moderno y el advenimiento de Tailwind CSS v4, estas razones ya no aplican:

Característica Con Sass (Antipatrón) Con VeltraUI (CSS + Tailwind v4)
Variables y Dark Mode Variables estáticas en tiempo de compilación. No responden en vivo en el navegador. Variables CSS dinámicas en tiempo real (--vlt-*) con cambio de tema instantáneo.
Dependencias y Vite Obliga a instalar sass y sass-loader en Laravel/Vite, ralentizando el build. Cero dependencias extra. El motor LightningCSS procesa todo nativamente a hipervelocidad.
Anidamiento (Nesting) Requiere el preprocesador Sass. CSS Nesting nativo estándar del W3C soportado por todos los navegadores modernos.
Portabilidad de Componentes Bloqueado a proyectos que configuren Sass. 100% portable a Blade, React, Vue, Svelte y Angular sin configurar nada.

Historically, developers depended on Sass for three primary reasons: variables ($color), selector nesting, and mixins. With modern native CSS standards and Tailwind CSS v4, these justifications are obsolete:

Feature With Sass (Legacy) With VeltraUI (CSS + Tailwind v4)
Variables & Dark Mode Compile-time static variables. Cannot switch dynamically at runtime. Dynamic runtime CSS variables (--vlt-*) with instant zero-reload theme changes.
Tooling & Vite Forces users to install heavy sass binaries into their Laravel/Vite projects. Zero extra dependencies. LightningCSS parses everything natively at maximum speed.
CSS Nesting Requires a Sass compiler to unroll nested selectors. W3C native CSS nesting standard natively supported across all modern browsers.
Component Portability Locked into projects with explicit Sass configuration. 100% portable to Blade, React, Vue, Svelte, and Angular out of the box.

8. Modo Oscuro Anti-FOUC Persistente 8. Anti-FOUC Persistent Dark Mode Architecture

Cómo evitar el parpadeo blanco y sincronizar con localStorage How to prevent white flashes and sync with localStorage

El FOUC (Flash of Unstyled Content) ocurre cuando el script que activa el modo oscuro se ejecuta después de que el navegador ya comenzó a pintar los elementos en pantalla con fondo blanco. Para erradicarlo al 100%, VeltraUI utiliza una función autoejecutable sincrónica en el <head> que evalúa el tema antes de renderizar el primer nodo HTML: FOUC (Flash of Unstyled Content) occurs when the dark mode script executes after the browser has already begun painting the initial light-themed DOM. To eliminate it completely, VeltraUI uses a synchronous self-invoking script in the document <head> that runs before the first HTML node is painted:

HTML <head> — Script Anti-FOUC Canónico 
<script>
  (function() {
    try {
      const savedTheme = localStorage.getItem('veltra-theme') || 'light';
      document.documentElement.setAttribute('data-theme', savedTheme);
      if (savedTheme === 'dark') {
        document.documentElement.classList.add('dark');
      } else {
        document.documentElement.classList.remove('dark');
      }
    } catch (e) {}
  })();
</script>
Compatibilidad dual: VeltraUI actualiza al mismo tiempo tanto el atributo data-theme="dark" (para variables CSS) como la clase .dark (para utilidades de Tailwind como dark:bg-slate-900). De este modo, cualquier librería o componente de terceros funciona a la perfección.
