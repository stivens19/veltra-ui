CARACTERÍSTICAS

Por qué usar VeltraUI

Diseñado para ofrecer una arquitectura limpia, ligera y lista para producción en tus proyectos.

Arquitectura 100% Nativa

Sin compiladores pesados ni binarios que ralenticen tu build. Todo utiliza CSS Nesting nativo del W3C y variables CSS vivas en tiempo de ejecución.

Tailwind CSS v4 Nativo

Olvídate de tailwind.config.js. Funciona con @import "tailwindcss"; nativo y compila a hipervelocidad mediante LightningCSS y Vite 6.

Modo Oscuro Anti-FOUC

Cero parpadeos blancos molestos al recargar. Un script canónico autoejecutable en el <head> evalúa el tema y sincroniza localStorage al instante.

17 Componentes Puros

Cards con colapso, maximizado a pantalla completa y eliminación fade-out, modales con tecla ESC, acordeones treeview y pestañas fluidas.

Portabilidad Multi-Framework

Úsalo en Laravel Blade mediante componentes <x-ui.*>, o cópialo a React, Next.js, Vue y Angular sin cambiar tu flujo de desarrollo.

Licencia Permisiva MIT

100% de libertad para proyectos personales, comerciales, SaaS o aplicaciones internas de clientes. Sin regalías ni restricciones ocultas.

INTEGRACIÓN SENCILLA

Listo Para Usar en Cualquier Entorno

Dos archivos limpios (css/veltra.css y js/veltra.js) es todo lo que necesitas.

Integración en Laravel Blade

resources/views/layouts/app.blade.php

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi App Laravel</title>
    <!-- Estilos VeltraUI con Tailwind v4 precompilado -->
    <link rel="stylesheet" href="{{ asset('css/veltra.css') }}">
</head>
<body class="bg-slate-50 dark:bg-slate-950">
    @yield('content')
    <script defer src="{{ asset('js/veltra.js') }}"></script>
</body>
</html>

Integración en React / Vite

src/main.jsx o src/App.tsx

import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';

// Importa los estilos de VeltraUI en un solo paso:
import './css/veltra.css';

ReactDOM.createRoot(document.getElementById('root')).render(
  <App />
);
